# Public release boundary

This repository freezes the code and small aggregate evidence used to audit the DMKD manuscript-active analysis.

## Included

- scripts `01`–`11` and supporting encoder/model modules;
- helper scripts for table generation and batch training;
- `number_mapping.md`, the manuscript-number to artifact/script crosswalk;
- `frozen_results/` aggregate CSV/JSON evidence used for headline-value checks;
- lightweight encoder tests and an aggregate-evidence verifier;
- reproducibility, citation, dependency, CI, and deterministic release-manifest tooling.

## Intentionally excluded

- cached raw UCI/OpenML downloads;
- processed arrays and row-level prediction NPZs;
- PyTorch checkpoints and other fitted model binaries;
- large generated figure/confusion-matrix collections;
- virtual environments, caches, LaTeX build products, or machine-specific paths;
- cover letters, reviewer suggestions, editorial correspondence, journal templates, and submission-management notes.

Public datasets are reacquired through `01_download_clean.py`; trained artifacts are regenerated by the documented pipeline. The small aggregate evidence is included so manuscript headline values can be checked without redistributing row-level data or large model files.
